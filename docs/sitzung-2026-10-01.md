## 4. Warum `index.html` von ca. 10 MB auf ca. 8 MB geschrumpft ist

Gemessen in der Git-Historie (`git cat-file -s <commit>:index.html`):

| Commit | Uhrzeit | Größe von index.html | Was |
|---|---|---|---|
| `4fb7083` | 07:43 | 11.170.181 Bytes (Windows zeigt ca. 10,6 MB) | letzter Stand mit 29 Liedern |
| `e30393d` | 07:51 | 8.481.432 Bytes (ca. 8,1 MB) | **5 Lieder entfernt, Schriften eingebettet** |
| `9a78695` | 07:57 | 8.483.318 Bytes | Stand zu Beginn dieser Sitzung (r30) |
| `44265c1` | 09:03 | 8.494.586 Bytes | Ende dieser Sitzung (r33), **+11.268 Bytes** durch den neuen Code |

**Ursache:** In Commit `e30393d` (vorherige Sitzung, Konzept-Runde 29) wurden fünf Lieder gelöscht, weil sie nach Fremdmaterial aussahen (Urheberrecht):

| Datei | Größe |
|---|---|
| `personaxmother.mp3` | 850.320 Bytes |
| `peronamorhwr.mp3` | 850.320 Bytes |
| `minecraft.mp3` | 210.240 Bytes |
| `sadmarioinb4.mp3` | 98.820 Bytes |
| `sadmariosda.mp3` | 94.500 Bytes |
| **Summe** | **2.104.200 Bytes MP3** |

`tools/build.py` bettet jede MP3 als Base64-Text in `index.html` ein. Base64 macht Dateien um ein Drittel größer: 2.104.200 × 4/3 = **2.805.600 Bytes weniger**. Gleichzeitig kamen die Schriften dazu (5 × woff2 = 87.488 Bytes, als Base64 ca. 116.650 Bytes). Unterm Strich ergibt das rechnerisch −2.688.950 Bytes, gemessen waren es −2.688.749 Bytes. Die restlichen ca. 200 Bytes sind Codeänderungen im selben Commit.

**Heute:** Die 24 verbleibenden Lieder haben zusammen 6.006.960 Bytes, als Base64 ca. 8,0 MB. Das sind **rund 94 % von `index.html`**. Der Code (game.html ca. 280 KB, PeerJS, Schriften) ist der kleine Rest.

Wer die Datei kleiner haben will, muss bei der Musik ansetzen: in kleinere Dateien aufteilen, niedrigere Bitrate (z. B. 96 kbit/s) und erst bei Bedarf nachladen statt alles einzubetten (Release-Plan Punkt 3). Das geht aber nur, wenn das Spiel von einer Webseite statt als einzelne Datei geladen wird.

**Hinweis:** Die gelöschten Lieder sind weiterhin in der Git-Historie des öffentlichen Repos enthalten. Die Historie umzuschreiben wurde Ali früher angeboten, ist aber nicht passiert.
